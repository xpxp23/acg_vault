## 一、剧情背景与女主角核心心理真相剖析

### 1. 表面故事：小恶魔妹子的借住同居
主人公因受朋友（或朋友母亲落田阿姨）托付，临时在自己公寓中收留朋友的妹妹——「真理奈」同居借住 3 周时间。  
真理奈外形娇小甜美（148cm、40kg），但性格举止却极其轻浮、大胆、充满挑衅与诱惑，张口闭口充满魅魔般的小恶魔挑逗，让单身的主人公每天都处于理智与欲望崩溃的边缘。

### 2. 核心真相：伤痕累累的“恶女防卫机制”
随着剧情深入（特别是触发 **`Event_KyoseiEvent_2`（强迫事件2）** 和 **`Event_Kaminari_1`（雷雨夜事件）** 后），真理奈隐藏在玩世不恭面具下的悲惨真相被彻底揭开：
* **童年到青春期的持续骚扰**：真理奈因为天生貌美娇柔，从中学起每天在通勤电车上遭遇各种痴汉咸猪手，放学路上屡遭怪人尾随跟踪，男人们看她的目光始终充满了恶心与下流。
* **前借住家庭的背叛**：在借住到主人公家之前，真理奈寄住在落田阿姨家。表面上落田先生是长辈，私下里却同样试图对真理奈图谋不轨。
* **恶女的诞生**：为了在满是色狼的险恶世界中生存，真理奈发展出了一套极端扭曲的**自卫反击机制**——既然男人们都想占我便宜，那我就反客为主用美貌诱惑他们，把他们当提款机榨干金钱；一旦给不出钱，就直接以“猥亵未成年犯罪”报警逮捕送他们进监狱！
* **初遇当夜的真相**：第一天主角喝醉，真理奈本想故技重施，但主角即使喝得烂醉也只是傻笑打呼睡觉，毫无越轨行为。真理奈心有不甘，趁主角熟睡时强行取精制造“既成事实”。
* **三周同居的本质**：这是真理奈对主角展开的一场“人性考核”。
  - 如果主角和别的男人一样，贪图一时肉欲、满脑子白嫖与占便宜（恶女度 `Akujyo > 0`），真理奈就会冷酷地判定“你和那些恶心男人毫无区别”，在 3 周后将主角彻底当成供养奴隶（ED4）甚至没钱时报警抓走（ED6）；
  - 只有当主角坚守做人底线、真正尊重她、倾听理解她的创伤，并在雷雨天给予她真正的避风港时，真理奈心中的**「不动之心」**（封闭的心防）才会被彻底击碎，露出那个渴望被爱、纯情羞涩的真实自我（ED1 真结局）！

## 二、核心数值系统与状态判定机制详解

游戏底层通过 `PlayData` 与 `StatusData` 维护主角与真理奈的数值体系：

```
                    ┌─────────────────────────┐
                    │  PlayData 核心状态管理   │
                    └────────────┬────────────┘
         ┌───────────────────────┼───────────────────────┐
         ▼                       ▼                       ▼
   心智与道德数值           经济与行动参数           肉体感度与家庭
  ├── Koukando (好感度)    ├── Cash (现金)          ├── OkuchiLevel (口交)
  ├── Akujyo (恶女度)      ├── WorkPower (专业度)   ├── MuneLevel (乳交)
  ├── YuwakuCount (诱惑)   └── Day (同居天数1~19)   ├── CliLevel (阴蒂)
  └── YuwakuEscape (抗诱)                           ├── ChitsuLevel (阴道)
                                                    ├── OsiriLevel (肛门)
                                                    ├── Kekkon (结婚戒指)
                                                    └── Ninsin / Syussan (怀孕生子)
```

### 1. 五大核心心智属性
| 属性名 | 内部变量 | 机制与影响 |
| :--- | :--- | :--- |
| **好感度** | `koukando` | 真理奈对主角的内心好感。通过日常对话、赠送礼物、阅读恋爱书籍（`book02`）、雷雨天安抚提升。**真结局 ED1 要求 `koukando > 12`**。 |
| **恶女度** | `akujyo` | 真理奈把主角当成玩物/色狼的程度。若在诱惑事件中沉沦、在强迫事件2中选择轻浮插入，此数值上升。**真结局 ED1 与纯爱线要求 `akujyo <= 0`**。 |
| **诱惑次数** | `yuwakuCount` | 主角被真理奈诱惑并顺从发生色色互动的累计次数。在恶女线上，`>= 6` 进 ED4（提款机），`< 6` 进 ED5。 |
| **抗拒诱惑次数** | `yuwakuEscapeCount` | 主角拒绝真理奈诱惑、保持理智的次数。有助于压制恶女度。 |
| **色色度/变态度** | `inran` / `hentai` | 主角与真理奈的性开放程度。可通过阅读情色书籍（`book03`）提升，解锁更多色色姿势。 |

### 2. 身体五大部位感度开发等级
* **口交等级（`OkuchiLevel`）**：嘴部互动与深喉技能开发。
* **乳房等级（`MuneLevel`）**：揉胸、吸吮与乳交技能开发。
* **阴蒂等级（`CliLevel`）**：爱抚与玩具挑逗阴蒂感度。
* **阴道等级（`ChitsuLevel`）**：本番插入与抽插接纳度。
* **臀部等级（`OsiriLevel`）**：后庭玩具与肛交开发。
> 各部位经验随着互动次数提升，升级后将解锁全新的呻吟表情、Live2D动作与特殊高潮反应。

### 3. 经济管理与破产红线
* **金钱（`Cash`）**：通过“打工”（Work）赚取。每次打工获得的报酬受**专业度（`WorkPower`）**加成。可通过阅读服装类书籍（`book01`）提升专业度（+3）。
* **破产红线（`Cash < 0`）**：真理奈的许多换装、外卖、道具需要花钱。**切记！任何时候如果因为消费导致金钱为负数，将瞬间无视主线直接触发 ED6 破产逮捕 BAD END！**

## 三、主线全 6 大结局触发条件与分支树

游戏在 **第 19 天（Day 19）** 会执行 `GetEndingScenario` 核心判定逻辑，代码流程完全解密如下：

```
                    【第 19 天 结局判定日】
                              │
                    ┌─────────┴─────────┐
                    │   Akujyo > 0 ?    │
                    └─────────┬─────────┘
                   No         │         Yes
         ┌────────────────────┘         └────────────────────┐
         ▼                                                   ▼
┌──────────────────────────┐                       ┌───────────────────┐
│ success_KaminariEvent == true? │                 │ YuwakuCount >= 6? │
└────────────┬─────────────┘                       └─────────┬─────────┘
       Yes   │   No                                    Yes   │   No
  ┌──────────┴──────────┐                               ┌────┴────┐
  ▼                     ▼                               ▼         ▼
┌──────────────┐   【ED3 封闭离别】                  【ED4 提款玩物】 【ED5 隐忍考验】
│Koukando > 12?│
└──────┬───────┘
  Yes  │   No
  ┌────┴────┐
  ▼         ▼
【ED1】   【ED2 擦肩告白】
  │
  ├─ 选择「等等……！」 ────► 【ED1 Branch B：True End 恋人确立·不动之心碎裂·解锁无尽模式】
  └─ 选择「就这样道别」 ──► 【ED1 Branch A：普通道别·真理奈去向不明】
```

### 1. ED1：真结局（True End·不动之心碎裂·解锁无尽模式）
* **达成判定**：
  1. 到达第 19 天（`Day == 19`）；
  2. 恶女度零污染：`akujyo <= 0`；
  3. 雷雨夜安抚成功：`success_KaminariEventBranch == true`；
  4. 好感度达标：`koukando > 12`；
  5. 剧情末尾出现抉择：
     - `就这样道别` ➔ 触发 **ED1 Branch A**；
     - **`等等……！` ➔ 触发 ED1 Branch B（真结局·True End）**！
* **剧情高潮**：
  主角大声叫住准备离开的真理奈，袒露自己的真心。真理奈终于彻底撕下所有伪装，满脸羞红地承认自己第一次真心喜欢上男人，主角是她的初恋！系统提示**「不动之心」碎裂**，两人正式成为恋人，**彻底解锁无尽模式（Endless Mode）**！

### 2. ED1 Branch A：惆怅道别结局
* **达成判定**：在 ED1 末尾选择「就这样道别」。
* **剧情**：主角未能鼓起勇气挽留，真理奈如蝴蝶般飘然而去。主角之后打电话确认，对方称真理奈根本没有去报道，真理奈消失在人海中，令人怅然若失。

### 3. ED2：擦肩而过的告白结局（好感不足）
* **达成判定**：
  1. `Day == 19`；
  2. `akujyo <= 0` 且 `success_KaminariEventBranch == true`；
  3. 但好感度较低：`koukando <= 12`。
* **剧情**：
  离别前，真理奈坦白初遇当晚其实主角什么都没做，是她自己趁主角睡着取精的。真理奈承认这次是自己输了，“下次见面，我一定会让你真正迷上我的”，随后微笑着离开。

### 4. ED3：封闭心房的离别结局（雷雨事件失败）
* **达成判定**：
  1. `Day == 19`；
  2. `akujyo <= 0`；
  3. 雷雨夜安抚失败：`success_KaminariEventBranch == false`（雷雨夜选择了敷衍的借耳塞选项）。
* **剧情**：
  因为主角未能在关键时刻走进真理奈内心，真理奈依然保持礼貌而疏离的态度，三周一到便礼貌道谢离去，从此再无音讯。

### 5. ED4：恶女玩物·终身提款机结局（恶女堕落）
* **达成判定**：
  1. `Day == 19`；
  2. 恶女度偏高：`akujyo > 0`；
  3. 屈服诱惑次数较多：`yuwakuCount >= 6`。
* **剧情**：
  主角完全沦为了真理奈的掌中玩物。临走前真理奈用蔑视又得意的口吻命令：“以后无聊的时候我可能会联系你哦，不管你在哪里都要立刻赶过来♡ 为了以后能一直供养真理奈，要好好工作当提款机哦♡”，主角唯命是从。

### 6. ED5：隐忍的耐力考验结局（意志坚定）
* **达成判定**：
  1. `Day == 19`；
  2. `akujyo > 0`；
  3. 但屈服诱惑次数较少：`yuwakuCount < 6`。
* **剧情**：
  三周结束，真理奈调侃主角：“很努力地在・忍・耐对吧？呵呵♡ 以后想见真理奈随时可以联系我哦”，留下联络方式后从容离去。

### 7. ED6：身败名裂·破产逮捕 BAD END（金钱负数）
* **达成判定**：
  - 游戏任何一天，在诱惑或消费事件中，若主角金钱变负（`cash < 0`），立即触发！
* **剧情**：
  真理奈瞬间变脸：“你怎么没钱啊？难道你以为本小姐会免费陪恶心大叔舒服吗？这可是货真价实的犯罪哦♡”，随后直接报警。警笛长鸣，主角被警车押走，身败名裂宣告游戏结束！

## 四、全日程事件时间轴与关键分歧抉择

### 1. 第 1 ~ 4 天：破冰同居与日常奠基
* **Day 1（初到之日）**：

* **Day 2（厕所事件）**：
  - 触发强制事件 `Toirehajime`。在卫生间撞见真理奈，小恶魔试探开始。
* **Day 3（温馨聚餐）**：
  - 触发强制事件 `Event_Gohan_1`。两人一起吃晚饭，选择夸赞料理可提升好感度。
* **Day 4（手机网购解禁）**：
  - 解锁手机商城 Erozon 与打工系统。

### 2. 第 5 ~ 9 天：护花事件与日常魔性试探
* **Day 5（放学跟踪狂事件·好感分水岭）**：
  - 触发强制事件 `Event_KyoseiEvent_1`。
  - 主角傍晚去接真理奈放学，目睹真理奈被怪异男人尾随纠缠。主角挺身而出为真理奈解围，让真理奈第一次感受到主角与那些恶心男人的不同。
* **Day 6 ~ 9（魔性诱惑连击）**：
  - 陆续触发各种诱惑事件：打游戏挑逗（`h_yuuwaku_game`）、浴室借毛巾（`h_yuuwaku_furo`）、念课文撩拨（`h_yuuwaku_onndoku`）、扫除与揉肩诱惑等。
  - **攻略提示（走真结局纯爱路线）**：尽量保持理智与体贴，不要表现出急不可耐的猴急模样，避免恶女度暴涨；保证身上留有充足现金，防止被意外扣费触发 ED6。

### 3. 第 10 ~ 11 天：【绝对核心分歧】强迫事件2与电话真相
* **触发条件**：第 10 天夜晚接到落田阿姨打来的电话（`Event_KyoseiEvent_2`）。
* **剧情揭秘**：
  落田阿姨在电话中向主角道歉，并透露了真理奈在前一个借住家庭遭遇的事情——落田阿姨的丈夫对真理奈意图不轨，而真理奈为了自保勒索巨款并报警将其抓捕。
* **致命分支选择**：
  - ❌ **选择 Branch A（顺从欲望 / 强行插入）**：
    真理奈会跨坐上来并嘲讽：“什么嘛……哥哥和其他男人果然是一模一样的嘛～”。恶女度 `akujyo` 大幅飙升，永久关闭 ED1/ED2/ED3，直接滑向 ED4/ED5 恶女玩物路线！
  - ✅ **选择 Branch B（坚决克制 / 促膝长谈）**：
    主角严肃地制止真理奈：“不要这样了……我听落田阿姨说了关于她先生的事情……”，真理奈破防后吐露自己从小被痴汉、跟踪狂骚扰的心酸经历。主角表示理解与心疼，**恶女度被清零压制，成功保住真结局路线**！

### 4. 雷雨之夜：【灵魂抉择】雷雨安抚事件
* **触发事件**：`Event_Kaminari_1`（暴雨雷鸣之夜）。
* **剧情发展**：
  外面雷声大作，平时不可一世的小恶魔真理奈吓得瑟瑟发抖，尖叫着扑进主角怀里（`EV4_006`：“对、对不起……真理奈特别害怕打雷……”）。
