## 一、核心数值与特殊机制详解

### 1. 恶堕度系统（EvilLevel）与杀戮机制
游戏内无黑存在隐藏数值 **击杀数（KillCount）** 与对应的 **恶堕等级（EvilLevel）**：
* **Lv 0（正道武士）**：击杀数 = 0。无黑眼神坚定，维持正统武士风范。
* **Lv 1（心生戾气）**：击杀数 >= 1。开启部分冷酷对话选项。
* **Lv 2（嗜血残虐）**：击杀数 >= 20。无黑表情变得阴暗凶戾，可接取高风险刺杀任务。
* **Lv 3（修罗恶堕）**：击杀数 >= 30（游戏内上限）。眼神完全黑化，直接解锁白夜路线【杀人魔无黑】恶堕结局与浪人路线【大和的支配者】结局！

> 💡 **如何提升杀戮数**：
> 在第3章之后的部分任务（如 `CommonSys*Murder`、`SC_D04_13`）、夜间暗杀事件、街头平民与侍卫处决选项中选择「杀掉/处决/灭口」，击杀数即可增加。

---

### 2. 性开发度与淫乱度晋升（Immoral Rank）
角色的淫乱度分为 **Rank D（纯洁） -> Rank C（初开） -> Rank B（熟稔） -> Rank A（痴女）**。
淫乱度并非直接增加数值，而是由 **口交、小穴、菊穴** 三大器官的独立开发度共同决定：
* **淫乱度升至 Rank C**：口交开发度 >= C 且 小穴开发度 >= C 且 菊穴开发度 >= C。
* **淫乱度升至 Rank B**：口交开发度 >= B 且 小穴开发度 >= B 且 菊穴开发度 >= B。
* **淫乱度升至 Rank A**：口交开发度 >= A 且 小穴开发度 >= A 且 菊穴开发度 >= A。

各器官开发度晋升要求（以主角无黑为例）：
| 开发器官 | Rank C 条件 | Rank B 条件 | Rank A 条件 |
| :--- | :--- | :--- | :--- |
| **口交开发度** | 吹箫次数 >= 1 | 吹箫次数 >= 15 且 口内射精量 >= 100ml | 吹箫次数 >= 30 且 口内射精量 >= 200ml 且 章节 >= 第4章 |
| **乳房开发度** | 揉胸次数 >= 10 | 揉胸次数 >= 20 | 揉胸次数 >= 30 且 乳交次数 >= 10 且 章节 >= 第4章 |
| **小穴开发度** | 破处（失去处女） | 做爱次数 >= 20 且 膣内中出精液量 >= 150ml | 做爱次数 >= 50 且 膣内中出精液量 >= 300ml 且 章节 >= 第4章 |
| **菊穴开发度** | 肛交次数 >= 1 | 肛交次数 >= 15 且 后庭中出精液量 >= 100ml | 肛交次数 >= 30 且 后庭中出精液量 >= 200ml 且 章节 >= 第4章 |
| **暴露开发度** | 露出次数 >= 10 | 露出次数 >= 20 | 露出次数 >= 30 且 触发特定露出事件旗标（Flag 473） |

> 桃（Momo）、黄菜子（Kinako）、冥（Mei）亦具备相同的晋升逻辑体系。浪人路线淫乱结局要求 **无黑、桃、黄菜子三人全员达到 Rank A 淫乱度**！

### 3. 生理周期、受孕与生产系统
女主拥有完整的生理周期系统，周期数值随步数推进而循环切换：
* **安全期（Safe Day）**：基础怀孕概率极低（2%），持续约 200 步。
* **普通期（Normal Day）**：基础怀孕概率中等（10%），持续约 400 步。
* **危险期（Unsafe Day）**：受孕概率极高（**75%**），持续约 200 步！危险期内如遭遇无套中出极易中奖！
* **避孕药（MenstrualCycle_Pill）**：在道具店购买或商人处获得，服用后可提供 1000 步的绝对避孕免疫状态。
* **受孕与生产**：怀孕后角色立绘将变为腹部隆起的受孕形态，经历一定步数后可在屯所或安全屋触发独立生产事件，解锁对应的分娩回想与子代图鉴。

---

### 4. 外派风俗（Delehel）与公厕露出机制
* **外派风俗服务（Delehel）**：
  在各城镇地下风俗店或委托人处可开启外派接客。游戏内置了多达 **300 名各具特色的常客名单**（涵盖巨根、戴套要求、技术高超、变态嗜好等类型）。完成接客可获得丰厚报酬并迅速提升对应器官开发度与射精积累量。
* **公共厕所与街头露出**：
  帝都公共厕所及偏僻小巷在开发度达到 C 以上时可互动，可选择当众解手、小解偷窥、野外露出或接受流浪汉/浪人猥亵。

## 三、共通第3章核心分歧点详细攻略

共通第 3 章是决定全游戏通往三大主线命运的十字路口。玩家在第 3 章的操作将直接锁定后续路线：

### 分歧途径 1：进入【浪人路线（掳走俘虏线）】
1. 在第 3 章执行日常任务与剧情战时，故意战败或任务失败累计达到 **3 次以上**（判定函数 `RootJudge >= 3`）：
   - 涉及任务包括：`SC_A03_03`（退治）、`SC_A03_05`、`SC_A03_07`、`SC_A03_08`、`SC_A03_09`、`SC_A03_10`、`SC_A03_13` 等。
2. 满足失败 3 次后，系统不会触发正规护卫任务，而是在深夜强制触发 `SC_A03_19`（夜道遭浪人袭击）。
3. 在该战斗中 **选择故意败北**，无黑将被浪人集团轮番侵犯蹂躏，随后被带走彻底脱离鬼灯队，直接开启 **浪人路线（第4章 SC_D04_01）**！

### 分歧途径 2：进入【浪人路线（主动离队线）】
1. 在前 3 章通过外派服务、战败凌辱或公厕互动，将无黑的 **淫乱度（Immoral）提升至 Rank B 以上**。
2. 正常推进第 3 章至末尾 `SC_A03_17`，无黑夜晚在驻地反思感到躁动难耐，此时会解锁专属隐藏二选一选项：
   - 「去吹吹夜风冷静一下」
   - **「就这样离开去别的地方吧」**
3. 选择 **「就这样离开去别的地方吧」**，无黑厌倦规矩选择自我放逐，直接进线至 **浪人路线（第4章 SC_D04_05）**！

### 分歧途径 3：进入【鬼灯路线】或【白夜路线】
1. 正常完成第 3 章各项主要任务（失败次数 < 3 且未在 A03_17 主动离队）。
2. 剧情推进至 `SC_A03_18`（在山中与姐姐神八代冥秘密接触）。
3. 冥向无黑指出幕府的腐朽并发出同行邀请，此时出现关键历史抉择：
   - **选择【回想迄今为止发生的事情】**：无黑重拾同伴羁绊与身为幕府武士的初心，拒绝姐姐并返回鬼灯屯所，锁定 **【鬼灯路线】（SC_B04_01）**！
   - **选择【跟着姐姐离开】**：无黑看透幕府暴政，决意跟随至亲之人拯救底层，离开鬼灯加入白夜，锁定 **【白夜路线】（SC_C04_01）**！

## 五、售后剧场 (After Story 全部8个) 解析与解锁指南

通关特定路线或全解锁后，标题菜单的 **【After Story】** 将开放全部 8 个专属后日谈剧场：

1. **AfterStory 01:《在约定之日来临之前缠绵个够》**
   - **登场角色**：无黑 × 莱欧
   - **剧情解析**：鬼灯纯爱结局的甜蜜售后。战后二人终于确定关系，在约定出远门之前，无黑与莱欧在房中恩爱缠绵一整天。
2. **AfterStory 02:《心动不已的混浴》**
   - **登场角色**：桐生桃 × 风真银
   - **剧情解析**：桃与一直守护自己的青梅竹马银成为恋人后，二人一同前往秘汤混浴温泉，展现了桃害羞而深情的一面。
3. **AfterStory 03:《杰诺返回大和的那天》**
   - **登场角色**：黄菜子 × 杰诺
   - **剧情解析**：讲述了异国剑士杰诺在暂别大和后再次返回，与心心念念的黄菜子重逢并加深羁绊的温馨故事。

## 七、战斗技巧、强力武器饰品与技能配置推荐

### 1. 队伍阵容与核心角色定位
* **神八代无黑（主物理斩杀）**：
  - 单体物理爆发全队第一。主力配置居合系列与连续居合斩。配合高暴击率饰品可轻松实现单回合破万伤害。
* **桐生桃（属性魔法与群体压制）**：
  - 擅长火/冰/雷属性全场魔法打击与全队 HP 恢复。在面对复数杂兵和多部位 Boss（如大太法师）时为必选核心。
* **黄菜子（高速敏捷、弱点异常与破防）**：
  - 拥有全队最高的速度成长，先手施加眩晕、剧毒或盲目，并能削减敌方高额防御力。
* **神八代冥 / 莱欧（强力特化支援）**：
  - 冥具备极高的范围剑术与斩铁破甲；莱欧则拥有变身为黑夜叉的爆发状态，短时间内无视防御。

### 2. 名刀与顶级装备推荐
* **名刀·虎彻**：白夜路线第 5 章商人委托获取，自带高暴击率与反击特性。
* **村正妖刀**：恶堕路线专属极品武器，击杀数越高攻击力加成越夸张。
* **八尺琼勾玉（饰品）**：全属性抗性大幅提高，大幅减少技能 SP 消耗。
* **避邪神符 / 银制护身符**：免疫绝大多数战斗 H 异常状态与行动不能。
