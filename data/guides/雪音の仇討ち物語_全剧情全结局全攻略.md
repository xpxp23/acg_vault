## 一、故事全主线剧情深度解析

### 1. 序章与血海深仇之源：妙灵山惨剧
两年前，和平宁静的雪女秘境“妙灵山”突然遭到幕府正规军与阴阳院术士的联合血腥清洗。幕府以“人妖共存、驱逐恶煞”为伪善借口，暗中派遣阴阳院术士、武将荒木兵马以及叛乱山鬼，将雪女全村屠戮殆尽。年幼的女童被当场残杀，年轻的雪女遭百般凌辱后枭首焚尸。  
雪音亲眼目睹同胞被火海吞噬、亲族被屠杀，内心中只剩下冰冷刺骨的杀意。她发誓必定要手刃所有参与灭族的五大主谋，将他们的五脏六腑彻底冻碎！

### 2. 第一仇敌：武家屋敷·荒木兵马的诛灭
经过两年的潜伏与隐忍，雪音首先锁定了驻扎在城下町近郊武家屋敷的荒木兵马。  
荒木身为幕府武官，当年在妙灵山奸杀掠夺无恶不作。雪音孤身潜入戒备森严的武家大宅，冰霜之气席卷厅堂。面对死到临头仍狂妄叫嚣的荒木，雪音毫不留情，将其双腿冻结碎裂，并质问其当年暴行。荒木在极度痛苦中求饶，最终被雪音凝结出的冰华从内脏彻底爆裂诛杀。雪音回收了村落遗失的神兵【冰结刀】。

### 3. 第二仇敌：故乡故土·妙灵山山鬼贾克莫的背叛
为了前往雪女故乡妙灵山调查当年背叛者的下落，雪音结识了在此经商的人类少女**荠菜（なずな）**。荠菜虽是市井商人，但深明大义，主动拿出通行手形带雪音入山。  
在妙灵山废墟深处，雪音找到了勾结阴阳院的恶鬼头目**贾克莫（ジャクモ）**。贾克莫不仅不知悔改，反而嘲弄雪女的软弱，并透露一个让雪音浑身震颤的秘密——**雪音的亲姐姐“冰雨”当年并未阵亡，而是被作为战利品卖给了山下恶商油谷利兵卫，如今正在城下町的游郭沦为娼妇肉便器！**  
愤怒至极的雪音彻底击溃贾克莫及其手下，冰刃封喉，斩杀第二位仇敌。

### 4. 第三仇敌：血色游郭·解救亲姐冰雨与斩杀油谷
雪音与荠菜火速赶赴城下町红灯区“游郭”。黑商油谷利兵卫依仗阴阳院的结界术式，在此贩卖走私妖怪、开设肉宴。  
雪音暴力破开游郭的阴阳封印结界，深入内室救出被铁链禁锢、受尽两年屈辱的姐姐冰雨。油谷狗急跳墙，放出从海外走私驯养的凶残改造异形兽“伪白虎”。雪音与冰雨合力斩杀巨兽，油谷跪地哀求并提起与冰雨的床第私情试图免死，冰雨甚至不等其说完，拔刀出鞘神速瞬斩，将油谷的肥头当场削成肉末！姐妹二人终于重逢。

### 5. 河畔奇遇：与白鸟少女“萤”的宿命交织
在策划对阴阳院发起总攻的间隙，雪音偶遇了阴阳院传闻中最令人闻风丧胆的黑衣少女——**萤（ほたる）**。  
出乎意料的是，私底下的萤并非嗜杀狂魔，而是一个眼神空洞、毫无俗世常识、连笑与哭都不会的白纸般的女孩。在城外春日的河滩上，萤小心翼翼地捧着一只翅膀受伤流血的小白鸟，因自己只会毁灭不会疗伤而茫然无措。  
雪音撕下衣袖细心为小鸟包扎骨折，萤给小鸟取名为“大福”。两个同为命运所操弄的少女在河滩上并肩而坐，萤第一次向雪音露出了笨拙却纯真的笑容，并轻轻问雪音：“我们……是朋友吗？”那一刻，雪音心中复仇的坚冰第一次泛起了涟漪。

### 6. 第四仇敌：阴阳院本殿·天羽玄明的陨落与真相反转
为了彻底铲除灭族惨剧的幕后策划者，雪音在荠菜的潜入策应与冰雨的掩护下，杀入阴阳院本殿中枢，与首魁**天羽玄明**展开殊死决战。  
战斗陷入苦战，重创天羽后，黑衣少女萤奉命赶来支援。天羽得意洋洋地下令让萤将雪音两姐妹烧成灰烬，并狂妄道出令人毛骨悚然的真相：  
> **萤并非人类，而是十多年前被幕府消灭的大妖怪“九尾之狐”女帝的遗孤！** 天羽与阴阳院当年灭其族、斩其母，用秘宝“杀生石”剥夺了萤作为生灵的一切记忆与情感，将她作为毫无痛觉与是非观的活体杀戮机器驱使！

天羽疯狂咒骂萤是低等畜生，厉声勒令其动手。然而，萤的手指剧烈颤抖，眼角滑落泪水。回想起在河边与雪音的温情约定，萤在极度的痛苦中哀求天羽收回命令。当天羽暴跳如雷甚至准备施法折磨萤时，**萤内心的羁绊战胜了禁锢，抬手射出一记毁灭性的妖火之矢，当场将天羽玄明的心脉贯穿烧焦！**  
天羽毙命，阴阳院覆灭，萤因打破禁令陷入极度恐慌而仓皇逃遁。

### 7. 终章决战：白鹭城天守阁·杀生石与将军三河赖秀
随着阴阳院垮台，一切线索直指整个国家最高权力的顶点——**白鹭城将军·三河赖秀**。  
原来，三河赖秀所谓“人妖共存”的施政完全是一场精心策划的世纪谎言！他将白鹭城地下改造成人间地狱般的活体屠宰场，以共存为名诱骗妖怪进城，实则日夜进行剥皮、抽髓、提取人鱼血试图炼制不老不死药。而当年屠灭妙灵山雪女一族，也是因为他垂涎雪女的绝美与长生之血！  
冰雨潜入调查险遭暗算，雪音、冰雨与荠菜一同杀上白鹭城天守阁。在御庭番众的包围下，雪音施展全力，抢夺到了控制萤命运的关键核心——**【杀生石】**！  
此时，宿命的抉择摆在了雪音的眼前……

### 1. 【真结局 / 幸福结局】ENDING 15：ハッピーエンド（携手赴京·百合后日谈）
* **达成步骤**：
  1. 在天守阁夺下杀生石后，面对选项选择：**【殺生石を破壊する】（破坏杀生石）**。
  2. 杀生石应声碎裂，被封印十数年的九尾之狐毁灭妖火狂暴涌出。萤恢复了全部力量与母亲的毁灭记忆，认定人类全部该死，并偏执地想要杀光所有人、把雪音永远占为己有。
  3. 冰雨掷出烟幕弹，雪音护着荠菜暂时撤离天守阁，回到城下町荠菜的住处（Map 017）。
  4. 与荠菜对话，荠菜倾囊相助，拿出精心研制的禁忌兴奋秘药**『真·泥屠露异头』**。雪音一饮而尽，全身妖力激增沸腾，怀揣着杀生石残片重返白鹭城天守阁。
  5. **终局单挑决战：与【觉醒萤（覚醒蛍）】战斗并取得胜利！**
* **结局剧情**：
  - 战斗结束后，雪音利用手中的杀生石残片，巧妙吸收了萤体内失控暴走的九尾余威。
  - 萤脱力倒在地上嚎啕大哭，质问雪音为何自己无论怎么做都不被认可。雪音紧紧将泣不成声的少女拥入怀中，温柔开导：“你以前见过的只有人渣，但世界上还有很多美好的人和事。在我们一起看完整个世界前，不要轻易决定放弃它。”
  - 一个月后，三河赖秀与阴阳院暗中残害妖怪的地下活体实验室被公之于众，真相大白于天下。
  - 冰雨启程北上妙灵山祭拜族人，并寻找其他失散的雪女遗民；荠菜留在城下町大发横财并守护市井；
  - **雪音与萤结伴乘上巨型妖鸟“风丸（カゼマル）”，在绚烂的夕阳与云海中飞往京都，去祭拜萤生母的陵墓**。
  - **通关专属后日谈（回想15 / Event 8）**：旅途中的每间客栈夜里，萤都像缠人的小野兽一样依偎在雪音身边，以笨拙却无比深情的方式日夜爱抚雪音，两人沉浸在甜蜜温馨的百合爱欲中，共同守护着来之不易的和平。

### 2. 【坏结局 / 悲情结局】ENDING 40：BADEND、見世物 / 贖罪（公众展览·终身奴隶）
* **达成步骤**：
  1. 在天守阁面对选项选择：**【殺生石を破壊しない】（不破坏杀生石）**。
  2. 雪音深知不能像天羽和三河那样将萤当做武器驱使，于是她将妖力注入杀生石，以主人的身份下达了唯一的命令：“杀生石啊，解除对萤的一切束缚，还她自由！”随后，雪音以平等的“朋友”身份向萤求助：“萤，帮帮我！”
  3. 萤第一次凭自己的意志行动，爆发神火将御庭番众化为焦炭并为雪音疗伤。雪音亲手斩杀幕后黑手三河赖秀。
  4. 战后，雪音将完好的杀生石交还给萤，约定在城外河滩再会后撤离。
* **结局剧情**：
  - 雪音等人走后，恢复神智的萤看着满地死尸与被杀戮的历史，陷入深深的罪恶感中。她深知世人不会放过刺杀将军的凶手，为了不让雪音背负弑君罪名，**萤选择留下来，放火烧掉将军尸体，独自承担全部罪名**。
  - 雪音与冰雨返回北方，荠菜回到城下町。然而城中并未迎来曙光，新幕府将杀生石改造成最残酷的精神刑具，强行放大萤的所有羞耻心、痛觉与敏感神经，**将她作为“弑君大罪人”绑在广场中心公开示众（见世物）**！
  - 愚昧狂怒的暴民向她投掷石块，恶徒兵丁在光天化日之下轮番当众奸淫摧残她，萤在痛哭哀求与生不如死的地狱中沦为公用肉便器，直至最后被公开斩首。赶回来的荠菜在人群外目睹这惨绝人寰的一幕，痛苦失声。

### 3. 【崩坏结局 / 绝望结局】ENDING 14：覚醒蛍敗北（肉壁触手监禁·人间地狱）
* **达成步骤**：
  1. 天守阁选择【破壊する】（破坏杀生石）。
  2. 回到城下町喝下秘药后重返天守阁。
  3. **在与【觉醒萤（覚醒蛍）】的决战中战败！**
* **结局剧情**：
  - 雪音药效耗尽不敌觉醒神力的萤。彻底疯狂的萤将天守阁化作由血肉与触手组成的魔性结界。
  - 萤将雪音永远囚禁在充满超强媚毒的肉壁之中，触手灌注灼热精液，对雪音进行永无休止的绝顶折磨。
  - 萤病态地微笑着抚摸雪音：“就算雪音的身心彻底崩溃坏掉，我也会用母亲的秘术不断把你治好……生生世世，我们永远是最好的朋友♡”
  - 雪音在精神崩溃与永恒的潮吹中彻底沦为萤的肉偶。十年后，整个日之本因疯狂的暴政彻底沦为尸山血海的“人间地狱”，从世界的地图上被彻底抹除。

## 四、全 40 个回想（H-Event / CG）完整收集速查指南

游戏中共有 40 个独立事件/CG，根据回想室（Map 043）精确排列与触发条件如下：

### 【雪音篇】（回想 01 ~ 15）
1. **01. 武家屋敷道中敗北**：第一章武家屋敷输给特定小怪。
2. **02. 武家屋敷荒木敗北**：第一章决战输给 BOSS 荒木兵马。
3. **03. 妙霊山道中敗北**：第二章雪山道中输给特定小怪。
4. **04. 妙霊山ジャクモ敗北**：第二章决战输给 BOSS 贾克莫。
